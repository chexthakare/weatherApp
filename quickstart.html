🎯 How to Use

  1. Automatic Location: Click the 📍 location button to use your current location
  2. Search City: Type any city name in the search bar and press Enter or click Search
  3. Autocomplete: Start typing to see location suggestions
  4. View Forecast: Scroll down to see the 7-day forecast and weekly summary
  5. Hover Effects: Hover over forecast cards for interactive animations

Edit the CSS variables in style.css:

Modify Weather Icons

Update the getWeatherInfo() function in script.js to use custom icons or images.

🐛 Troubleshooting

Common Issues:
  • Location not found: Check your internet connection and try a different city name
  • Geolocation denied: Allow location access in your browser settings or search manually
  • PHP errors: Ensure you're using PHP 8.1 or higher (php -v)
  • Styling issues: Clear your browser cache (Ctrl+Shift+R)
  • API errors: Check browser console (F12) for detailed error messages
